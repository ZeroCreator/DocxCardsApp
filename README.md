# Docx Cards - Приложение для управления карточками знаний

![Electron](https://img.shields.io/badge/Electron-47848F?style=for-the-badge&logo=Electron&logoColor=white)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

Приложение для Windows для работы с файлами .docx в виде карточек знаний. Поддерживает импорт/экспорт, форматирование, изображения, таблицы и красивое отображение контента.

## ✨ Возможности

- 📝 **Красивое отображение** .docx файлов в виде карточек
- 🏷️ **Организация по темам/категориям**
- ✨ **Поддержка форматирования**: жирный, курсив, таблицы, изображения
- 📤 **Экспорт** карточек в .docx (одна или все карточки)
- 📥 **Импорт** карточек из .docx файлов
- 🔍 **Поиск и фильтрация** по карточкам
- 🎨 **Современный интерфейс** с пастельной зеленой цветовой схемой
- 📱 **Адаптивный дизайн**

## 🚀 Установка и запуск

### Требования
- Node.js 14 или выше
- npm 6 или выше
- Windows 7/8/10/11

### Установка
```bash
# Клонировать репозиторий
git clone https://github.com/ваш-username/docx-cards.git
cd docx-cards

# Установить зависимости
npm install

# Запустить в режиме разработки
npm start

# Собрать приложение для Windows
npm run build
```

## Скрипты npm

- npm start - запуск в режиме разработки
- npm run build - сборка приложения для Windows
- npm run package - упаковка приложения
- npm run make - создание установщика

## 🎯 Использование

**Создание карточки**

- Нажмите "Новая карточка" в верхнем меню
- Заполните название, категорию и метаданные
- Добавьте содержание в нужные блоки (описание, симптомы, ключи и т.д.)
- Используйте редактор для форматирования текста
- Сохраните карточку

**Импорт из .docx**

- Перейдите в "Импорт из .docx" в боковом меню
- Перетащите или выберите .docx файл
- 
Файл будет преобразован в карточку

**Экспорт в .docx**

- Откройте карточку
- Нажмите "Экспорт в .docx"
- Выберите место сохранения
- 
Карточка будет экспортирована со всеми данными и форматированием


## 🔧 Технологии

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend:** Electron, Node.js
- **Файлы:** mammoth.js для работы с .docx
- **Хранение данных:** localStorage
- **Стили:** Кастомный CSS с пастельной зеленой темой


## 📝 Формат данных карточки

**Карточка содержит следующие блоки:**
- Основная информация (название, категория, метаданные)
- Ключевая характеристика
- Описание
- Типичные особенности
- Симптомы (общие, психические, частные)
- Модальности
- Ключи
- Тип личности
- Источники
И другие специализированные блоки
